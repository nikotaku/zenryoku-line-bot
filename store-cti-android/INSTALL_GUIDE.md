# INSTALL_GUIDE.md — 店舗CTI 導入説明書

対象: 店舗管理者・導入担当者(Android端末の基本操作ができる方)

## 1. 必要なもの

- Android 10 (API 29) 以上のスマートフォン(店舗の070/080/090番号のSIMが入った端末)
- APKファイル: `app-debug.apk`(初期配布)または署名済み `app-release.apk`
  - GitHub Actions の成果物 `store-cti-debug-apk` からダウンロード、
    または開発PCで `./gradlew :app:assembleDebug` を実行して
    `store-cti-android/app/build/outputs/apk/debug/` から取得

## 2. APKのインストール(直接配布)

1. APKファイルを端末へコピーする(USB転送、社内共有ドライブ、メール添付など。**公開の場所に置かない**)
2. 端末の「ファイル」アプリでAPKをタップ
3. 「提供元不明のアプリのインストール」を求められたら、**ファイルアプリに対してのみ**「この提供元を許可」を一時的にON
4. 「インストール」をタップ
5. インストール完了後、**許可を元に戻す(OFF)**ことを推奨
6. Playプロテクトの警告が出た場合は「詳細」→「インストールする」(社内配布アプリのため)

## 3. 初期設定(最初に必ず行う)

1. アプリを起動 → 設定
2. **店舗情報**: 店舗名・店舗電話番号を入力して保存(SMS差し込みの {storeName} {storePhone} に使われます)
3. **スタッフ**: スタッフ名を全員分追加し、既定スタッフを選択
4. **営業時間・予約枠**: 開店/閉店時間と予約枠の標準時間(分)を設定
5. 必要に応じて: 電話番号マスク表示 / スクリーンショット禁止 をON
6. **端末に画面ロック(PIN・指紋・顔)を必ず設定**(顧客情報保護のため必須)
7. ホーム画面にアプリのショートカット(「着信対応」「クイックSMS」)を配置
   (アプリアイコンを長押し → ショートカットをドラッグ)

## 4. アップデート方法

1. 新しいAPK(**同じ署名**のもの)を入手
2. 2章と同じ手順で上書きインストール(データ・設定は保持されます)
3. **注意**: 署名の異なるAPK(例: debug版 → release版)は上書きできません。
   その場合は 設定 > バックアップを作成 → 旧アプリをアンインストール → 新APKをインストール → バックアップから復元

## 5. バックアップ運用(推奨: 週1回以上)

1. 設定 > バックアップを作成(JSON) → 注意画面を確認 → 保存先を選択
2. 作成したファイルを店舗PCなど管理された保管場所へ移動し、端末内から削除
3. 復元は 設定 > バックアップから復元(現在のデータは全置換。実行前に自動プリバックアップが内部に作成されます)

## 6. release APK の署名手順(開発担当者向け)

初期配布はdebug署名APKで問題ありませんが、正式運用ではrelease署名を推奨します。

### 6-1. 署名鍵の作成(初回のみ)

```bash
keytool -genkeypair -v \
  -keystore store-cti-release.jks \
  -alias storecti \
  -keyalg RSA -keysize 2048 -validity 10000
```

- 鍵ファイル(`.jks`)とパスワードは**リポジトリに入れない**。管理者が安全に保管する
- 鍵を紛失すると同じ署名でのアップデートができなくなります(全端末で再インストールが必要)

### 6-2. keystore.properties の作成

プロジェクトルート(`store-cti-android/`)に `keystore.properties` を作成(gitignore済み):

```properties
storeFile=/絶対パス/store-cti-release.jks
storePassword=（キーストアのパスワード）
keyAlias=storecti
keyPassword=（鍵のパスワード）
```

### 6-3. ビルド

```bash
cd store-cti-android
./gradlew :app:assembleRelease
# 出力: app/build/outputs/apk/release/app-release.apk(署名済み)
```

`keystore.properties` が無い場合、releaseビルドは未署名(インストール不可)になります。

## 7. アンインストール・端末返却時

1. 設定 > バックアップを作成(必要な場合)
2. 設定 > すべてのデータを削除(データ初期化)
3. アプリをアンインストール
4. 端末のDownloads等に出力済みCSV/バックアップが残っていないか確認して削除

## 8. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「電話アプリが見つかりません」 | 電話アプリのないタブレット等では発信できません。SIMの入ったスマートフォンを使用してください |
| 「SMSアプリが見つかりません」 | 同上。既定のSMSアプリが設定されているか確認してください |
| SMSアプリに本文が入っていない | 一部機種のSMSアプリは本文の引き継ぎに対応していません。アプリの本文を長押しコピーして貼り付けてください |
| 着信識別(実験機能)が動かない | 設定 > 着信識別 で役割が「許可済み」か、通知が許可されているか確認。端末により非対応です(Phase 1機能はすべて利用可能) |
| 復元に失敗する | ファイルが本アプリのバックアップ(JSON)か確認。壊れている場合、現在のデータは変更されません |
| 空き容量不足で保存できない | 端末のストレージを空けてから再実行してください |
