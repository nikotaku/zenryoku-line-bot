## 3. 実機で確認すべき項目(最終動作確認表)

APKインストール後、以下を順に確認してください。

### 基本(完了条件に対応)

- [ ] アプリが起動し、ホーム画面が表示される
- [ ] 設定 > 店舗情報を保存し、**アプリ再起動後も保持されている**
- [ ] スタッフを2名登録し、既定スタッフを設定できる
- [ ] 新規顧客を登録できる(氏名・電話番号必須チェック、区分選択)
- [ ] 同じ電話番号で2人目を登録しようとすると**重複警告**が出る
- [ ] 顧客一覧で「090 1234 5678」「09012345678」「090-1234-5678」いずれでも同じ顧客が見つかる
- [ ] ふりがな・顧客番号でも検索できる。並び替え・注意顧客絞り込みが機能する
- [ ] 顧客詳細 >「電話する」で**標準電話アプリが番号入力済み**で開く(発信はしない)
- [ ] 顧客詳細 >「SMSを作成」→ テンプレート選択 → 本文編集 →「SMSアプリを開く」で**宛先・本文入力済み**のSMSアプリが開く
- [ ] SMS作成履歴が「SMSアプリを起動」状態で記録され、「スタッフ確認済み」に変更できる
- [ ] 対応履歴を登録できる(対応結果10種、折り返し要/済み)
- [ ] 対応履歴一覧の「折り返し未完了」フィルタとホームの未対応件数が一致する
- [ ] 予約を登録できる。同じ担当者で時間が重なる予約を登録すると**重複警告**が出る
- [ ] 予約一覧の本日/明日/日付指定/状態別/担当者別が機能する
- [ ] SMSテンプレートの差し込み({customerName} {reservationDate} {startTime} {storeName}等)が正しい値になる
- [ ] CSVを4種類出力し、**Excelで文字化けなく開ける**(BOM確認)。「=」で始まるメモが `'=` になっている
- [ ] バックアップ(JSON)を作成できる
- [ ] データ初期化 → バックアップから復元で、顧客・予約・設定が戻る
- [ ] 設定のON/OFF(マスク表示・スクリーンショット禁止)が即時反映される
- [ ] Android設定 > アプリ > 店舗CTI > 権限 に**電話・SMS関連の権限が存在しない**

### 経路・連携

- [ ] 電話アプリの通話履歴から番号をコピー → 着信対応画面「貼り付け」で顧客が表示される
- [ ] 他アプリでテキスト共有 → 共有先に「店舗CTI」→ 着信対応画面に番号が入る
- [ ] アイコン長押しショートカット「着信対応」「クイックSMS」が動く
- [ ] 未登録番号の検索 →「新規顧客として登録」で番号が引き継がれる

### Phase 2(対応端末のみ)

- [ ] 設定 > 着信識別を有効化 → 役割許可ダイアログ → 通知許可
- [ ] 別の電話から着信 → 顧客名入りの通知が表示される → タップで対応画面が開く
- [ ] 非対応端末では「この端末では利用できません」と表示される
- [ ] 着信識別を有効にしても着信が正常に受けられる(ブロックされない)

### 表示品質

- [ ] ダークモードで全画面が読める
- [ ] 端末のフォントサイズ最大でも操作可能(スクロールで全項目に到達できる)
- [ ] 注意顧客が色+アイコン+ラベルで区別されている
